      Rules, odds and transparency

      Language

      How to play

      1. Set your wager (and an optional auto-eject target) while boarding is open.
      2. At launch the multiplier climbs from 1.00× and keeps accelerating.
      3. Eject any time to collect wager × multiplier.
      4. If the rocket explodes before you eject, the wager is lost.

      Transparency

      Random number generator (RNG)
      Each launch's crash point comes from a fresh 256-bit seed drawn with a cryptographically secure RNG, mixed with HMAC-SHA256. It is fixed before boarding opens.
      Return to player (RTP)
      Server authority
      The server alone decides the crash point and judges every eject by the moment it arrives. This page only animates what the server reports.
      Auto eject (auto cash out)
      Runs on the server at exactly your target, even if your connection drops.
      Server idempotence
      Every bet and eject carries a unique key. A retried request returns the original result and is never applied twice.
      Multiplier curve

      Provably fair

      Before each launch the server publishes SHA-256(seed). After the explosion it reveals the seed, and this page recomputes the crash point itself.
